Installing on Windows
  1. Right-click the downloaded SYNAPSE-Browser-Windows-x64.zip and choose Extract All.
  2. Move the SYNAPSE Browser folder somewhere on your fastest drive (an SSD), such as your user folder.
  3. Open synapse.exe. If “Windows protected your PC” appears, choose More info → Run anyway. The browser isn't code-signed yet.
  4. Right-click synapse.exe → Show more options → Pin to taskbar to keep it handy.

Tips for speed

  • Keep it on an SSD. A browser reads many small files as it starts and loads pages; a hard disk makes everything wait.
  • The first start is the slowest. SYNAPSE Browser sets up your profile the first time it opens; later starts are quicker.
  • Close what you don't use. Tabs you leave alone are unloaded automatically when memory runs low, and come back when you click them.
