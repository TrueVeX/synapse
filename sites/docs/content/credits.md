SYNAPSE is created by **Revoori Ashwath Reddy** at **HumanForm Studios**. It's built on the work of many companies and open-source communities. This page credits each of them.

## Services

| Service | What SYNAPSE uses it for |
|---|---|
| [OpenRouter](https://openrouter.ai) | One API for AI models; streams every answer |
| [NVIDIA](https://www.nvidia.com) Nemotron | The default AI model |
| [Tavily](https://tavily.com) | Web search for every question |
| [Supabase](https://supabase.com) | Hosted PostgreSQL database |
| [Vercel](https://vercel.com) | Hosting for the website, backend, home page and docs |
| [Razorpay](https://razorpay.com) | Payments, UPI AutoPay and subscriptions in India |
| [Google Identity Services](https://developers.google.com/identity) | Continue with Google sign-in |
| [GitHub](https://github.com) | Source code and app downloads (Releases) |
| [Google Fonts](https://fonts.google.com) | Serves Inter and Source Serif 4 |

## Design

- **Interface components** from the [21st.dev](https://21st.dev) community: the Claude-style chat input, the "shining text" thinking animation, the pricing cards and the sign-up card, adapted for SYNAPSE.
- **Colour theme**: [Claude theme by @serafimcloud](https://21st.dev/@serafimcloud/themes/claude) on 21st.dev.
- **Fonts**: [Inter](https://rsms.me/inter/) by Rasmus Andersson, and [Source Serif 4](https://github.com/adobe-fonts/source-serif) by Frank Grießhammer for Adobe, both under the SIL Open Font License.
- **Logo and landing page**: original designs for SYNAPSE by HumanForm Studios. The landing page's article-style layout was inspired by AI product announcement pages.
